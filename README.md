# BC Voice 실제 저장형 MVP

이 버전은 단순 화면이 아니라, 제출한 익명 의견이 `data/db.json` 파일에 실제 저장됩니다.

## 실행 방법

```bash
npm install
npm run dev
```

실행 후 브라우저에서 아래 주소 접속:

```text
http://localhost:5173
```

## 함께 실행되는 것

- 프론트 화면: http://localhost:5173
- 저장 서버 API: http://localhost:4000

## 사용 흐름

1. `익명 Voice` 메뉴에서 의견 제출
2. `운영진` 메뉴에서 접수 확인
3. 접수 건 선택
4. 상태 변경 또는 답변 작성
5. 답변 내용은 `data/db.json`에 저장됨

## 현재 가능한 기능

- 익명 의견 접수
- 카테고리 선택
- 답변 희망 여부 선택
- 운영진 대시보드
- 접수/검토중/답변완료 상태 변경
- 운영진 답변 저장
- 로컬 파일 DB 저장
